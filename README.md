# Домашнее задание к работе 2

## Условие задачи
Известна стоимость 1 кг конфет, печенья и яблок. Найти стоимость всей покупки, если известно купили Х кг конфет, Y кг печенья и Z кг яблок.
## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить константы:
   - `sweets` = 3 — кг конфет.
   - `cookies` = 3 — кг печенья.
   - `apples` = 15 — кг яблок.
   - `sweets_1` = 170.0 - цена за 1 кг конфет.
   - `cookies_1`= 120.0 - цена за 1 кг печенья.
   - `apples_1`= 100.0 - цена за 1  кг яблок
3. Вычислить стоимость за вес каждого продукта:
   - `x`= `sweets*sweets_1` - сумма за килограммы конфет. 
   - `y`= `cookies*cookies_1` — сумма за килограммы печенья.
   - `с`= `apples*apples_1` - сумма за килограммы яблок.
4. Вычислить стоимость всей покупки:
   - `all`=`x+y+c` - общая сумма покупки.
5. Вывести результаты расчетов с подстановкой всех значений в текст.
6. **Конец**
